IGS-Abschlussrechner PWA, Version 0.4

Zur Installation auf Android alle Dateien auf einem HTTPS-Webserver veröffentlichen (z. B. GitHub Pages oder Netlify). Dann die Website in Chrome öffnen und über das Browsermenü „App installieren“ bzw. „Zum Startbildschirm hinzufügen“ wählen.

Ein lokales Öffnen von index.html per file:// erlaubt keine Service-Worker-Installation.

Die Berechnungsregeln sind weiterhin ein Prototyp und nicht verbindlich schulrechtlich validiert.
